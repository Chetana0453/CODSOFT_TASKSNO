# Task 5: Blog Website — The Curious Corner

A responsive blog website created for the CODSOFT Frontend Development Internship using HTML, CSS, and JavaScript.

## Features

- Homepage with a featured story
- Six article cards with images, titles, excerpts, and publish dates
- Categories and tags for organising articles
- Search by title, excerpt, or tag
- Category filtering
- Load More button
- Individual article pages
- Responsive navigation menu and footer
- Layouts for desktop, tablet, and mobile screens

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

- index.html — Homepage
- post.html — Article detail page
- style.css — Styling and responsive layouts
- script.js — Article data, search, filters, and navigation
- images/ — Article images

## How to Run

Download the project and open index.html in a browser.
You can also use the Live Server extension in VS Code.
