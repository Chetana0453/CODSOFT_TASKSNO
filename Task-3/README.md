# Task 3: Expense Tracker

A responsive income and expense tracking application created for the CODSOFT Frontend Development Internship.

## Implemented Features

- Add income and expense transactions
- Record descriptions, amounts, categories, and dates
- Display transaction history
- Calculate total income, total expenses, and current balance
- Delete transactions
- Save transactions using local storage
- Format amounts in Indian Rupees
- Responsive summary cards and form layout

## Pending Features

- Edit existing transactions
- Filter expenses by category

## Technologies Used

HTML, CSS, and JavaScript.

## Project Files

- index.html — Page structure
- style.css — Styling and responsive layout
- script.js — Transactions, calculations, and local storage

## How to Run

Open index.html in a browser or use Live Server in VS Code.
