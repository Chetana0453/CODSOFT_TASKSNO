# Task 1: Personal Portfolio Website

A responsive personal portfolio created for the CODSOFT Frontend Development Internship.

## Features

- Home, About, Skills, Projects, Resume, and Contact sections
- Project cards with images, descriptions, and links
- Downloadable resume
- Contact form validation
- Responsive navigation
- Layouts for desktop and mobile screens

## Technologies Used

HTML, CSS, and JavaScript.

## How to Run

Open index.html in a browser or use Live Server in VS Code.
